# Evidence

Record this project's verification evidence here, one file per run (for example `2026-11-02-sandbox-integrations.md`).

Each record states the requirement or decision IDs, the status (`PASS`, `FAIL`, `BLOCKED`, or `NOT VERIFIED`), the date, the commit SHA, the environment, the integration mode (`mocked`, `sandbox`, or `live`), the exact commands, a summary of the result, where the artifacts are, and the limitations. Evidence never contains secrets, tokens, or personal data.

`pnpm check:setup` prints a record for the integration checks, ready to paste.
